# Programming_Challenge_A
C++ Visual Creativity &amp; Optimization Challenge. Open to all skill levels.

# Pre-Requisites
Any C/C++ experience. A C++17 or better compiler/IDE.

# Supported Platforms / Software Dependencies
Windows/UWP 64bit: None. Vulkan SDK (optional)
MacOS ARM/64bit: None. Vulkan SDK (optional)
Linux 64bit: X11 or XWayland. Vulkan SDK (optional)

# Challenge Goal
Expand the provided base code to modify the pixel data on screen to produce visually interesting and asthetically pleasing effects.
You will be judged on how visually interesting and seemingly intentional your output appears to be.
This is a real-time animation challenge. Performance will also be judged. An update rate of < 30 will disqaulify an entry.
You may transition between different effects over time, looping back to the original effect in more than 3 minutes.
Use raw C++ code to edit the on-screen color array in the most interesting/pleasing ways you can come up with.

# Rules / Restrictions
You must utilize the two provided base files (main.cpp & Gateware.h) for screen updates.
No additional external libraries can be included/used. C++ std:: libraries are ok.
No additional Gateware libraries may be used without explicit organizer permissions.
Do not spawn additional/alternate windows or remove/adjust the update rate calculation.
External assets such as textures/models/fonts are not permitted unless generated procedurally.
Both 2D and/or 3D effects are permissable, however all comutations/mathematics must be orginally created for the challenge. 
If you are unsure if something is allowed, ask the organizers first.

Good Luck!
